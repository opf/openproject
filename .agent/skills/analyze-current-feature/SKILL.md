# Analyze Current Feature

The foundational first stage in Feature Evolution.

## Instructions
1. **Map System**: Identify all involved DocTypes, APIs, and React Components spanning the feature.
2. **Identify Bottlenecks**: Pinpoint logic that is structurally rigid, unmaintainable, or failing to scale.
3. **Scope Constraints**: Define the hard boundaries of what must be preserved.
4. **Next Action**: Transition to the `redesign-feature` skill.
