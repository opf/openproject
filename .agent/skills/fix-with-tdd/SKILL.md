# Fix with TDD

The implementation stage for rectifying software bugs.

## Instructions
1. **Write Test**: Add a failing `FrappeTestCase` or Vitest component test demonstrating the bug in isolation.
2. **Implement Fix**: Write the minimal, elegant code required to make the failing test pass.
3. **Refactor**: Cleanly format and structure the implemented fix adhering to project standards.
4. **Next Action**: Move to the `verify-fix` skill.
