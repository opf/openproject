# Triage Bug

The initiation stage of the deterministic bug fixing pipeline.

## Instructions
1. **Reproduce**: Confirm the bug exists and clearly identify exact reproduction steps.
2. **Isolate**: Narrow down the failure context (e.g., React client state, Frappe API layer, or Database tier).
3. **Document**: Capture expected behavior versus actual behavior.
4. **Next Action**: Move immediately to the `root-cause-analysis` skill.
