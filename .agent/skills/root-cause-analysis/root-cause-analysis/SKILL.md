# Root Cause Analysis

The investigative stage of the bug fixing pipeline.

## Instructions
1. **Trace Data**: Follow the execution path backward from the isolated failure point.
2. **Inspect**: Read relevant codebase files, observe diagnostic logs, or use testing utilities.
3. **Identify**: Pinpoint the precise flaw (e.g., missing parameter logic, incorrect query context, permission failure).
4. **Next Action**: Move to the `fix-with-tdd` skill to begin remediation.
