# OpenProject Avatars

To select which type of Avatars can be used in your OpenProject, navigate to **Administration -> Users and permissions -> Avatars**.

These settings control which avatar options users and administrators can select in the **Edit avatar** dialog:

- **Enable user gravatars**: Users can show the image they registered for their email address at Gravatar. This option is not available for groups.
- **Enable user custom avatars**: Users can upload a custom image. Administrators can also upload images for users and groups.

The **Initials** option is always available, also when both settings are disabled. Users and groups can always enter up to two characters of their own and choose a background color.

If you disable an option that a user or group has selected, OpenProject shows their initials instead. Uploaded images are kept, and they are shown again if you enable custom avatars again.

Users change their own avatar in their [account settings](../../../user-guide/account-settings/account/#set-an-avatar). Administrators change avatars in the [user administration](../users/#avatar) and the [group administration](../groups/#change-the-group-avatar).
