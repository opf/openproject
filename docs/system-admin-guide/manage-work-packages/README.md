# Manage work packages

In the work package administration, you can configure how work packages are structured, displayed, and managed across your OpenProject instance. Define work package types and variants, create reusable forms and workflows, manage custom fields, and configure statuses, priorities, and other settings to suit your organization's needs.

Navigate to *Administration → Work packages* to access the following configuration options.
