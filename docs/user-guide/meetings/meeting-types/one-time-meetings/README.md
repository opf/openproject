# One-time meetings

A **one-time meeting** in OpenProject is a single meeting scheduled for a specific date and time. Use it for meetings that happen only once, such as a kick-off, a workshop or an ad-hoc discussion. For meetings that take place regularly with the same structure, use [recurring meetings](../recurring-meetings/) instead.

> [!NOTE]
> The **Meetings module needs to be activated** in the [Project settings](../../../projects/project-settings/modules/) to be able to create and edit meetings.

## Create a one-time meeting

To create a one-time meeting, click the green **+ Meeting** button in the **Meetings** module and select **One-time**. Alternatively, from anywhere in OpenProject, click the **+** button in the header navigation, select **Meetings**, then **One-time meeting**. Both routes lead to the same creation steps: enter the title, location, start date and time, and duration of the meeting. If you have the [Meeting templates](../../meeting-features/meeting-templates/) Enterprise add-on, you can also start from a template.

For step-by-step instructions, see [Create a new meeting](../../meeting-features/meeting-creation/#create-a-new-meeting).

A new one-time meeting starts in [draft mode](../../meeting-features/meeting-modes/#meeting-draft-mode), so you can prepare it before participants are notified.

## Work with one-time meetings

All meeting features are available for one-time meetings:

| Topic | Content |
| --- | --- |
| [Meeting creation](../../meeting-features/meeting-creation/) | Create, edit, copy and delete meetings. |
| [Meeting templates](../../meeting-features/meeting-templates/) | Reuse a predefined meeting structure (Enterprise add-on). |
| [Meeting participants](../../meeting-features/meeting-participants/) | Invite participants and keep them informed. |
| [Meeting agenda](../../meeting-features/meeting-agenda/) | Prepare the agenda, sort and vote on agenda items. |
| [Meeting modes and status](../../meeting-features/meeting-modes/) | Draft mode, meeting status and presentation mode. |
| [Meeting outcomes](../../meeting-features/meeting-outcomes/) | Document decisions and follow-up tasks. |
| [Meeting follow-up](../../meeting-features/meeting-follow-up/) | Meeting history and PDF export. |

> [!TIP]
> You can also turn an occurrence of a recurring meeting into a one-time meeting. See [Edit a recurring meeting occurrence](../recurring-meetings/#edit-a-recurring-meeting-occurrence).
