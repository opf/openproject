# Known limitations (beta)

The OpenProject mobile app is currently released as a **Beta**. This means the core experience is available, but some capabilities are not yet supported or are still evolving.

This page lists the most important limitations to be aware of.

## Connectivity and offline use

- **Offline mode is not supported.** The app requires an active internet connection to load and sync content.
- Some content you recently opened may remain visible temporarily, but actions such as creating or updating items generally require connectivity.

## Notifications

- **Real-time push notifications are not available yet.**
    - You can still view notifications inside the app in **Notifications**.
    - If you rely on immediate alerts, you may need to check the app manually for updates.

## Deep linking

- **Deep linking is not supported yet**, meaning links that should open directly in the mobile app may open in a browser instead (or not resolve to the corresponding in-app screen).

## Feature coverage vs. web/desktop

The mobile app is a companion to the web/desktop application. Some advanced functionality available on the desktop is not yet available on mobile.

Common examples include:

- Not every module or feature from the web application is available in the mobile app yet.
- Most of the administrative or configuration actions may require using the web application.

## Search scope

- **Global search is limited to selected content types.**
    - Currently supported: **Work packages** and **Spaces/Projects**.
    - **Meetings** are planned but not fully available through global search yet.
    - New modules will be included in the search scope as they are developed.

## Desktop usage

- There is **no dedicated desktop app** for OpenProject Mobile.
- On macOS, a scaled-up iPad version may be available via the App Store, but it is not designed for desktop workflows and should be used with caution.

## Feedback

- If you run into an issue, please use **Settings and support → Give feedback** to report it (ideally with screenshots and steps to reproduce).
