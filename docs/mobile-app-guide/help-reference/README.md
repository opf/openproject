# Help and reference

The OpenProject mobile app includes several ways to help you get unstuck, understand features, and learn what to expect while the app continues to evolve.

This section is the entry point for:

- **Self-service help** (how things work, common questions)
- **Reference information** (known gaps and limitations, especially during beta phases)
- Guidance on where to go when something does not behave as expected
