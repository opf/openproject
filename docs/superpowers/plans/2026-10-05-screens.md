# Screens Implementation Plan

> **Dành cho agent thực thi:** làm tuần tự từng task; mỗi step dùng checkbox. Viết test trước, chạy thấy fail, rồi mới viết code. Commit sau mỗi task (dòng đầu < 72 ký tự, kèm trailer attribution của phiên).

**Goal:** Module `modules/screens` cho phép admin định nghĩa Screen (create/edit/view/transition) gồm Section và Item (field + vị trí), gom thành Screen Scheme (Type → screen theo ngữ cảnh), gán cho Project; Resolver trả layout hiệu lực (hợp nhất trạng thái Field Rules) qua API v3 và UI xem trước/quản trị.

**Architecture:** Rails engine `modules/screens` theo mẫu `modules/field_rules`. 6 bảng mới (`screens`, `screen_sections`, `screen_items`, `screen_schemes`, `screen_scheme_items`, `project_screen_schemes`). `Screens::Resolver` là nguồn sự thật, fail-open, cache theo request. **Không** prepend vào core, **không** ghi `FormConfiguration`, **không** enforce. Phụ thuộc mềm `FieldRules::Resolver`.

**Tech Stack:** Rails 8.1, RSpec, Primer ViewComponent + Turbo + Stimulus (TypeScript), Grape API v3.

**Spec (nguồn sự thật):** [../specs/2026-10-05-screens-design.md](../specs/2026-10-05-screens-design.md) · **Idea:** [../../ideas/idea-03.md](../../ideas/idea-03.md). Nếu plan và spec mâu thuẫn, spec thắng; ghi lại chênh lệch ở checklist.

## Global Constraints

- Không sửa Ruby core, không thêm cột/bảng vào bảng core. Ngoại lệ có chủ đích duy nhất: thêm controller Stimulus mới + đăng ký ở `frontend/src/stimulus/setup.ts` (Task 9).
- Không có "jira" trong tên bảng/class/route/permission/menu/i18n/API.
- Tên DB: `type_id`, `scheme_id` (khớp F02); ánh xạ idea ở spec §7.1.
- Không `DELETE` cho Screen/Scheme (model `prevent_destroy`); deactivate qua `PATCH {active}` (API) / member `deactivate` (admin UI).
- `screen_type` bất biến sau khi tạo (`attr_readonly`).
- Mọi thay đổi layout/scheme đi qua service có `with_lock`; cấm gán trực tiếp `section_id`/`position` từ params.
- Resolver: fail-open, cache `RequestStore`, không ghi DB; test env re-raise trừ tag `:fail_open`.
- Manage = admin; `assign_screen_scheme` trong `project_module nil`; GET định nghĩa cho user đã đăng nhập; resolver endpoint: 404 nếu project không visible hoặc type không bật; `diagnostics` chỉ cho admin/`assign_screen_scheme`.
- Mọi chuỗi UI qua `modules/screens/config/locales/en.yml`.
- Header copyright `#-- copyright … #++` cho Ruby; `//-- copyright … //++` cho TS (`rake copyright:update_typescript`).
- Quality gates mỗi task: `bundle exec rubocop <files>`, `erb_lint <files>` khi có ERB; task frontend: `cd frontend && npx eslint src/stimulus && npm run typecheck`.
- Chạy test: `bundle exec rspec modules/screens/spec/<path>`.

> **Môi trường:** phiên hiện tại chỉ có Ruby 3.3.6 (repo cần 4.0.7), không Postgres/Docker/node_modules ⇒ không chạy được RSpec/rubocop/eslint. Mọi step "chạy test" phải thực hiện trên máy dev (`bin/compose-dev rspec …`). Nếu không chạy được, ghi rõ ở checklist; **không** đánh dấu task là đã kiểm chứng.

```ruby
create_table :screens do |t|
  t.string :name, null: false, index: { unique: true }
  t.text :description
  t.string :screen_type, null: false
  t.boolean :active, null: false, default: true
  t.timestamps
  t.check_constraint "screen_type IN ('create','edit','view','transition')", name: "screens_type_check"
end

create_table :screen_sections do |t|
  t.references :screen, null: false, foreign_key: { on_delete: :cascade }, index: false
  t.string :name, null: false
  t.integer :position, null: false, default: 0
  t.timestamps
  t.index %i[id screen_id], unique: true
end
add_index :screen_sections, "screen_id, lower(name)", unique: true, name: "index_screen_sections_on_screen_and_lower_name"

create_table :screen_items do |t|
  t.bigint :screen_id, null: false
  t.bigint :section_id, null: false
  t.string :field_key, null: false
  t.integer :position, null: false, default: 0
  t.string :width, null: false, default: "full"
  t.boolean :visible, null: false, default: true
  t.timestamps
  t.index %i[screen_id field_key], unique: true
  t.index %i[section_id position]
  t.check_constraint "width IN ('full','half')", name: "screen_items_width_check"
end
add_foreign_key :screen_items, :screen_sections, column: %i[section_id screen_id],
                primary_key: %i[id screen_id], on_delete: :cascade
```
